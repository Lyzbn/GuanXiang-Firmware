01 / CASTING

两次按下，一爻成象。

第一次旋币，第二次起抛。三枚币各自落定，六爻自下而上形成；每一步都留有看清变化的时间。

起转

02

起抛

03

观变

重复六爻后，查看本卦、动爻与之卦。

02 / READING

三档阅读，由简入深。

64 卦的本卦和之卦均可选择短意、精意和古文。默认每卦两行四字短意；精意按卦势、义理、处事、辨误四节展开，古文显示完整卦辞。384 爻及用九、用六分别提供释义与精意，长文分节分页，16px 正文每屏最多四行。

经传原文、王弼注／孔颖达疏的古注节选、观象今释分别标明。今释为项目借助 AI 辅助编写并核对的现代文字，不是学者的现成译文；现代书目仅供延伸阅读，不表示授权或背书。古文收录 64 条卦辞及大象、384 条爻辞及小象，以及用九、用六和对应小象，并非全本《易传》。

3档阅读模式

设定阅读习惯

设置页按 T 循环切换并保存默认模式。动画仍可选择舒缓或利落，减少动态与音效独立开关。

临时换个读法

卦意页按 T 临时切换，并回到第一页；不改变保存的默认模式。用上下键或 Enter 翻页，短意与精意末页可继续读原文。

一爻读完，顺读其变

Enter 先读完当前卡，再按爻辞、小象、精意、下一动爻顺读，最后进入之卦；乾坤全动先读用九／用六。历史阅读不新增记录。

03 / SELF-STUDY

先识八卦，再读六十四。

首页按 L，直接进入离线自学。无需先起卦，也不会新增占卜历史。

01

12 课识八卦

从阴阳和自下而上的读画方向开始，以传统口诀配合卦画认识八卦；来源与项目解释分别说明。

02

上下卦叠六爻

↑↓ 选择上卦或下卦，←→ 切换八卦，实时看卦画、卦名与序号。下离上坎为既济，交换后为未济。

03

通读六十四卦

按通行卦序浏览，←→ 跳八卦。进入后读卦辞、大象、精意、六爻与出处；返回保留原目录或组合位置。

第一次使用

  1. 首页按 Enter 开始；可选记录所问。
  2. 每爻按两次 Enter，共完成六爻。
  3. 跟随页脚提示，进入本卦、动爻或之卦阅读。
  4. 首页 L 进入自学，H 查看历史，I 打开设置；设置页 T 保存默认阅读模式。
  5. 卦意页 T 临时切换；↑↓ 或 Enter 翻页。
