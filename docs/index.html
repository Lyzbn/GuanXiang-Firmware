三币 · 六爻
01 / CASTING

两次按下，一爻成象。

第一次旋币，第二次起抛。三枚币各自落定，六爻自下而上形成；每一步都留有看清变化的时间。

01

起转

按下 Enter，三枚钱币开始旋转。

02

起抛

再次按下 Enter，等待三枚钱币分别落定。

03

观变

重复六爻后，查看本卦、动爻与之卦。

02 / READING

三档阅读，由简入深。

64 卦的本卦和之卦均可选择短意、精意和古文。默认每卦两行四字短意；精意提供较完整的现代阐释，古文显示完整卦辞，长文都可逐页读完。

现代文本由项目依据古典注疏整理，并非现成学者译文。古文范围为 64 条完整卦辞、384 条爻辞、384 条小象，以及适用的用九、用六和对应小象，并非全本《易传》。

64卦与古典卦辞
384爻辞与小象
12条本机历史
3档阅读模式

设定阅读习惯

设置页按 T 循环切换并保存默认模式。动画仍可选择舒缓或利落，减少动态与音效独立开关。

临时换个读法

卦意页按 T 临时切换，并回到第一页；不改变保存的默认模式。用上下键或 Enter 翻页，短意与精意末页可继续读原文。

回看已有记录

历史按保存的默认模式重新打开，阅读不会新增历史。动爻继续提供完整爻辞与小象。

选择适合自己的安装方式。

仅适配 M5Stack Cardputer ADV。下载前先区分首次安装与已有观象升级，按发行包说明核对文件和分区。

完整合并固件

从地址 0x0 烧录，包含启动程序、分区表与应用。会重置历史和设置，请先备份。

写入 0x10000，不写 NVS。要求分区布局相同、当前从 app0 启动，具体检查以升级说明为准。

第一次使用

  1. 首页按 Enter 开始；可选记录所问。
  2. 每爻按两次 Enter，共完成六爻。
  3. 跟随页脚提示，进入本卦、动爻或之卦阅读。
  4. 首页 H 查看历史，I 打开设置；设置页 T 保存默认阅读模式。
  5. 卦意页 T 临时切换；↑↓ 或 Enter 翻页。
