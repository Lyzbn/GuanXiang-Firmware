# 观象 · GuanXiang

面向 **M5Stack Cardputer ADV** 的离线三币六爻固件。近黑与暖金的横屏界面，让六爻依次形成，再阅读本卦、动爻和之卦。

**1.1.0 候选已完成构建与主机验证，固件尚未正式发布。** 已选定 Linux CI 应用镜像；新版尚未烧录验收，许可与重链材料已备齐。源码仓库保持私有。[English](README.en.md)

## 三档阅读

64 卦的本卦与之卦均可选择：

| 模式 | 内容 |
| --- | --- |
| 短意（默认） | 每卦两行四字的现代提示 |
| 精意 | 更完整的现代阐释，长段落逐页阅读 |
| 古文 | 完整卦辞，按页显示，不使用截短的两行摘句 |

现代短意与精意由项目依据古典注疏整理，并非现成学者译文。古文范围为 64 条完整卦辞，以及独立查看的 384 条爻辞、384 条小象；符合条件时可读用九、用六及对应小象。这不是全本《易传》。

参见[文本来源与整理说明](TEXT_SOURCES.md)，或直接核验[全部 64 卦现代文字及逐条出处](readings.json)。

首页按 **I** 打开设置，按 **T** 循环切换并保存默认阅读模式。在本卦或之卦的卦意页，**T** 只临时切换当前阅读模式，不改默认设置；切换后从第一页开始。打开一条历史时重新采用已保存的默认模式，阅读不会新增历史。

用 **↑↓** 翻页，或按 **Enter** 逐页前进。短意、精意末页可进入完整原文；古文读完直接进入后续页面，避免重复读同篇卦辞。动爻仍提供完整爻辞和小象。

## 其他功能

- 每爻两次 Enter：旋币、起抛；三枚币分别落定，六爻共 12 次操作。
- 本卦、动爻、之卦自由查看，多动爻可连续顺读。
- 舒缓／利落两档节奏，音效和减少动态独立设置。
- 可选 24 字节 ASCII 所问、12 条本机历史；无需网络或 microSD。

## 安装与升级

以下是拟提供的发行资产；最终文件名、校验值和命令以正式发行包为准。

| 使用场景 | 写入方式 | 历史与设置 |
| --- | --- | --- |
| 首次安装或从其他固件切换 | 合并固件写入 `0x0` | 会重置；先保留重要记录 |
| 相同分区布局且从 app0 启动的观象 | 应用固件写入 `0x10000` | 不写 NVS；须先通过兼容性检查 |

新阅读模式使用独立存储键，现有历史及设置格式保持不变。应用升级的离线检查已通过；新版设备上的历史保留和冷启动仍待验收。许可与匹配所选镜像的重链材料已备齐，当前没有可下载的 1.1.0 正式资产。

## 快速开始

1. 首页按 Enter 开始；可先记录所问，也可留空。
2. 每爻按一次 Enter 旋币，再按一次起抛，等待三枚币落定。
3. 六爻完成后按屏幕提示查看本卦、动爻和之卦，用 T 临时切换阅读模式。
4. 首页 H 查看历史，I 打开设置；设置页 T 保存阅读模式，P 切换节奏。

界面与卦文为中文。英文说明不代表固件内置英文界面。
