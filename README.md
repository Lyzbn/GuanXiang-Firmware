# 观象 · GuanXiang

面向 **M5Stack Cardputer ADV** 的离线三币六爻与自学固件。近黑与暖金的横屏界面，让六爻依次形成，再阅读本卦、动爻和之卦；也可从八卦入门，独立学习六十四卦。

**v1.1.0-rc.1 已公开预发行**，支持三档阅读、动爻顺读与六十四卦自学，已通过固定源码 CI 和本轮实机验收。自学卦卡为全部 64 卦提供 40px 大字卦名与卦图。[下载预发行固件](https://github.com/Lyzbn/GuanXiang-Firmware/releases/tag/v1.1.0-rc.1)。源码仓库保持私有。[English](README.en.md)

## 三档阅读

64 卦的本卦与之卦均可选择：

| 模式 | 内容 |
| --- | --- |
| 短意（默认） | 每卦两行四字的现代提示 |
| 精意 | 每卦按卦势、义理、处事、辨误四节展开，附古注节选与出处 |
| 古文 | 完整卦辞，按页显示，不使用截短的两行摘句 |

深化精意覆盖 **64 卦**，逐爻部分覆盖 **384 爻及用九、用六，共 386 份解读**，分别说明原注取义与当代处事启示。长文分节分页，保留 16px 正文，每屏最多四行。

经传原文、王弼注／孔颖达疏的古注节选、观象今释分别标明。今释为本项目据古典注疏、借助 AI 辅助编写并核对的文字，不是古注作者或现代学者的现成白话译文；现代书目仅供延伸阅读，不表示授权或背书。古文范围为 64 条完整卦辞、64 条大象、384 条爻辞与 384 条小象，另有用九、用六及对应小象；这不是全本《易传》。

参见[文本来源与整理说明](TEXT_SOURCES.md)，核验[64 卦与 386 份逐爻／用辞解读及出处](readings.json)，或查看[12 课、卦画与 64 卦大象数据](study-content.json)。

首页按 **I** 打开设置，按 **T** 循环切换并保存默认阅读模式。在本卦或之卦的卦意页，**T** 只临时切换当前阅读模式，不改默认设置；切换后从第一页开始。打开一条历史时重新采用已保存的默认模式，阅读不会新增历史。

用 **↑↓** 翻页，或按 **Enter** 逐页前进。动爻阅读会先读完当前卡的全部页，再依次进入 **爻辞 → 小象 → 精意 → 下一动爻 → 之卦**；多动爻末项直接进入之卦，乾坤全动先完成用九／用六。左右键仍可主动切换资料卡。

## 六十四卦自学

首页按 **L** 进入，无需先起卦，也不会新增占卜历史：

1. **12 课识八卦**：从阴阳、由下而上的读画方向开始，用传统口诀与卦画对照认识八卦。
2. **叠六爻**：选择上卦和下卦，实时查看组合后的六爻、卦名与序号；例如下离上坎为既济，交换后为未济。↑↓ 选择上／下卦，←→ 切换八卦。

3. **读六十四卦**：按通行卦序浏览，←→ 跳八卦；进入后共用卦辞、大象、精意、六爻与出处，返回保留目录或组合位置。

自学卦象卡先用 **40px 大字卦名与左侧卦图** 展示当前卦，上方辨认上下卦，底部保留两句短意；全部 64 卦使用同一层级。

## 其他功能

- 每爻两次 Enter：旋币、起抛；三枚币分别落定，六爻共 12 次操作。
- 本卦、动爻、之卦自由查看，多动爻可连续顺读。
- 舒缓／利落两档节奏，音效和减少动态独立设置。
- 可选 24 字节 ASCII 所问、12 条本机历史；无需网络或 microSD。

## 安装与升级

预发行提供以下安装方式；按发行包中的文件名、校验值和命令安装。

| 使用场景 | 写入方式 | 历史与设置 |
| --- | --- | --- |
| 首次安装或从其他固件切换 | 合并固件写入 `0x0` | 会重置；先保留重要记录 |
| 相同分区布局且从 app0 启动的观象 | 应用固件写入 `0x10000` | 不写 NVS；须先通过兼容性检查 |

现有历史及设置格式保持不变。用户已确认大字卦卡显示满意、旧历史与设置保留，完整本卦／动爻到之卦阅读正常且新历史只增加一条，USB 与电池分别冷启动正常并保留新数据。预发行安装包、摘要和重链材料见[下载页](https://github.com/Lyzbn/GuanXiang-Firmware/releases/tag/v1.1.0-rc.1)。

## 快速开始

1. 首页按 Enter 开始；可先记录所问，也可留空。
2. 每爻按一次 Enter 旋币，再按一次起抛，等待三枚币落定。
3. 六爻完成后按屏幕提示查看本卦、动爻和之卦，用 T 临时切换阅读模式。
4. 首页 L 进入自学，H 查看历史，I 打开设置；设置页 T 保存阅读模式，P 切换节奏。

界面与卦文为中文。英文说明不代表固件内置英文界面。
